
# Loan Default Risk Prediction System

## Overview

A machine learning project that predicts potential loan default using applicant and loan-related information. It uses an XGBoost classifier and a preprocessing pipeline.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- XGBoost
- Streamlit
- Joblib

## Features

- Accepts applicant and loan details through a web interface.
- Preprocesses numerical and categorical features.
- Predicts the loan default class.
- Displays an estimated default probability.
- Shows an illustrative risk indicator.

## How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Start the application:

   python -m streamlit run app.py

## Disclaimer

Predictions are estimates and are not guaranteed real-world outcomes or financial advice.
